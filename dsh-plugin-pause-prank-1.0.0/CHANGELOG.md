## 0.1.1

- 修复:点「继续卸载」后弹窗又冒出来,反复几次都停不下来。
  - 原因:DSH 的客户端插件热更新会把同一个 bundle 再 apply 一次而不走卸载,
    同一页面里于是存在两套 window 监听器。一套把这一下补发给官方停止按钮时,
    另一套把它当成新的用户点击又拦下来,于是「点一次弹一次」。
  - 修法:把监听器、bypass 标记收进一个挂在 window 上的共享运行时
    (`__DSH_PAUSE_PRANK_RUNTIME__`)。新的一套安装前先拆掉旧的一套;
    补发的合成点击用共享 bypass 让所有副本一起放行;弹窗永远只允许一张。
  - 另外只接管 `isTrusted` 的真实点击,程序合成的 `.click()` 不再被当成用户操作。
